# Encore Relay

Плагин совместного редактирования для Obsidian (форк [Relay](https://github.com/no-instructions/Relay), MIT). Живые курсоры, синхронизация в реальном времени, offline-правки с merge, общие папки. Работает целиком на сервере команды Encore — `https://relay.encorefamily.ru`.

## Установка через BRAT (рекомендуется, с авто-обновлением)

1. В Obsidian установите плагин **BRAT** (Settings → Community plugins → Browse → «BRAT»).
2. Команда `BRAT: Add a beta plugin for testing` (или в настройках BRAT «Add beta plugin»).
3. Вставьте: `axencore/Encore-relay`
4. BRAT скачает плагин и включит его. Дальше он будет **обновляться автоматически** при выходе новых версий.

## Установка вручную

Скачайте `main.js`, `manifest.json`, `styles.css` из [Releases](../../releases) и положите в
`<волт>/.obsidian/plugins/system3-relay/`, затем включите плагин в Community plugins.

## Вход

`Ctrl+P` → **«Войти (почта/пароль)»** → почта и пароль, выданные администратором.
